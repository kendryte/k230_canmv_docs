## EC200M-CN Debugging

### Read/Write Commands

After the EC200M-CN module is enumerated, there are three ttyUSB interfaces: /dev/ttyUSB0, /dev/ttyUSB1, and /dev/ttyUSB2. We send AT commands through /dev/ttyUSB1

The command `wr /dev/ttyUSB1 [data]` is used to send AT commands. It will directly open the device, send the command, and then close the device.

The command `rd /dev/ttyUSB1` will start a read thread that blocks and reads the return results of AT commands. By default, it automatically exits after reading 150 bytes. You can use the `list_thread` command to check whether the thread is still running. If it has exited, you can restart it.

``` shell
msh />list_thread
thread               pri  status      sp     stack size max used left tick  error
-------------------- ---  ------- ---------- ----------  ------  ---------- ---
rd                    15  suspend 0x00000648 0x00000800    78%   0x0000000a OK
```

### AT Commands

#### Query Network Card Mode

The EC200M-CN hardware module supports two network card modes: ECM and RNDIS. The default is ECM mode, so we do not need to modify it. Just check whether it is correct.

Returning `"usbnet",1` indicates the current ECM network card mode, and returning `"usbnet",3` indicates the current RNDIS network card mode.

``` shell
msh />wr /dev/ttyUSB1 AT+QCFG="usbnet"
msh />AT+QCFG="usbnet"
+QCFG: "usbnet",1

OK

```

#### Set Network Card Mode

Because we use the ECM network card mode, modification is not required by default. However, if this module has been modified by other users, we can change it back to ECM mode, but the module needs to be restarted after the modification.

``` shell
msh />wr /dev/ttyUSB1 AT+QCFG="usbnet",1                    #Set to ECM network card mode
msh />AT+QCFG="usbnet",1
OK


msh />wr /dev/ttyUSB1 AT+CFUN=1,1                           #Send command to restart the module, or power cycle the board directly
msh />AT+CFUN=1,1

OK

```

#### Query SIM Card Status

After connecting the module with the SIM card inserted to the system, we can use the following command to check the SIM card status. If the status is incorrect, try unplugging and reinserting the SIM card or use a different SIM card.

``` shell
msh />wr /dev/ttyUSB1 AT+CPIN?
msh />AT+CPIN?
+CPIN: READY

OK

```
